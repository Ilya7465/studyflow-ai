Профиль

Подключение AI-модели

Как подключить настоящий ИИ — инструкция
1. Установите Node.js 18+.
2. В папке backend/ выполните npm install.
3. Задайте ключ модели в переменных окружения (.env или экспортом): провайдер zai (встроенный) или любой OpenAI-совместимый (OPENAI_API_KEY).
4. Запустите npm start — сервер отдаёт фронтенд и API на одном порту.
5. Ключ живёт только на сервере: браузер общается с /api/* и ключа не видит. Подробности — в README.md.

Демо-режим Premium только локально

Включает Premium-интерфейс локально, чтобы посмотреть все функции без сервера. Настоящая проверка тарифа и лимитов выполняется только на сервере — этот переключатель не влияет на сервер.
